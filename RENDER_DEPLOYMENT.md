## 🚀 Deployment Steps

### Step 1: Push to GitHub
```bash
git add .
git commit -m "Fix: Switch to Node runtime, update Dockerfile and render.yaml"
git push origin main
```

### Step 2: Create Render Service
1. Go to [Render Dashboard](https://dashboard.render.com)
2. **New** → **Web Service**
3. Connect your GitHub repo: `MERVINMICOSA/PAYROLL`
4. Configure:
   - **Name**: `philtech-payroll`
   - **Runtime**: **Node** ✅ (not Docker)
   - **Build Command**: `npm install` (auto-detected)
   - **Start Command**: `node server.js` (from package.json)
   - **Plan**: Free or Starter

### Step 3: Add PostgreSQL Database
1. **New** → **PostgreSQL**
2. **Name**: `philtech-payroll-db`
3. **Database**: `payroll_db`
4. **User**: `payroll_user`
5. **Version**: PostgreSQL 15
6. **Plan**: Free (if testing)

### Step 4: Link Database to Service
1. Go to service → **Environment**
2. Render auto-creates `DATABASE_URL` ✅
3. Verify it exists in the env vars list

### Step 5: Add Firebase Credentials
1. Service → **Environment** → **Add Variable**
2. **Key**: `FIREBASE_SERVICE_ACCOUNT`
3. **Value**: Your minified JSON from `FIREBASE_SETUP.md`
4. Click **Save**

### Step 6: Deploy
1. Service → **Deploy** (manual) or **Auto Deploy** (on git push)
2. Watch logs for:
   ```
   ✅ Server running at http://0.0.0.0:10000/
   ✅ PostgreSQL initialized
   ✅ Firebase Admin initialized
   ```

## ⚠️ Common Deployment Issues

### Issue: "Cannot find module 'pg'"
**Cause**: Dependencies not installed  
**Fix**: Check `package.json` has `"pg": "^8.x"`

### Issue: "Firebase initialization error"
**Cause**: `FIREBASE_SERVICE_ACCOUNT` not set or invalid JSON  
**Fix**: See `FIREBASE_SETUP.md` → Step 2-3

### Issue: "Database connection failed"
**Cause**: `DATABASE_URL` not linked  
**Fix**: Render → Service → Environment → Verify `DATABASE_URL` exists

### Issue: "Timeout connecting to database"
**Cause**: PostgreSQL not ready yet  
**Fix**: Render usually handles this; wait 2-3 minutes for DB to initialize
