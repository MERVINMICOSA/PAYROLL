## Implementation Steps

### 1. Update Database Initialization (PostgreSQL)
Modify `initializeDatabase()` function in `server.js`:
- Add teacher user creation alongside accountant and superadmin
- Create additional test employees if none exist

### 2. Update Firestore Initialization (Firebase)
Modify `initializeFirestore()` function in `server.js`:
- Add teacher user creation alongside accountant and superadmin
- Use same credentials as PostgreSQL teacher for consistency

### 3. Environment Variables
Ensure Firebase service account is configured in `.env` or platform environment:
```
FIREBASE_SERVICE_ACCOUNT={...}
```

### 4. Verification
After implementation:
- Test login for each account in both systems
- Verify employee data is accessible via `/api/employees` endpoint
- Confirm role-based redirects work correctly

## Security Notes
- Test passwords are weak and intended only for development/testing
- In production, these accounts should be removed or passwords changed
- Consider using environment variables for test credentials in future
